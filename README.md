# 🩺 Vaidya Mithra

Vaidya Mithra is an AI-powered healthcare assistance web application designed to provide users with:

- Symptom-based AI health assessment
- AI medical chatbot assistance
- Nearby hospital locator
- Symptom history tracking
- Responsive and modern UI

The application is built using **React**, **Firebase**, **Tailwind CSS**, and **Google Gemini AI**.

---

# 🌐 Live Demo

🔗 [Open Vaidya Mithra](https://vaidya-mithra-app.vercel.app)

# 🚀 Features

## 🔍 AI Symptom Prediction
Users can:
- Select symptoms from categorized lists
- Enter age and gender
- Get AI-generated possible conditions
- View confidence levels with visual indicators
- Receive emergency warnings for critical symptoms

---

## 🤖 DocBot – AI Health Assistant
An AI chatbot powered by Gemini AI that:
- Answers general medical questions
- Explains symptoms and conditions
- Provides safe and non-diagnostic advice
- Maintains chat history using Firebase Firestore

---

## 🏥 Nearby Hospital Finder
- Uses browser geolocation
- Redirects users to Google Maps
- Finds nearby hospitals and clinics instantly

---

## 📜 Recent History
- Stores previous symptom checks
- Uses Firebase Firestore for real-time data
- Displays latest assessments

---

## 📱 Responsive UI
- Mobile-friendly navigation
- Smooth animations
- Glassmorphism-inspired modern design
- Fully responsive layout using Tailwind CSS

# ⚙️ Environment Variables

Create a `.env` file in the root directory.

```env
VITE_FIREBASE_CONFIG=YOUR_FIREBASE_CONFIG
VITE_VAIDYA_MITHRA_GEMINI_KEY=YOUR_GEMINI_API_KEY
```

---

# 🔥 Firebase Setup

1. Create a Firebase Project
2. Enable:
   - Authentication → Anonymous Sign-In
   - Firestore Database
3. Copy Firebase configuration
4. Add it to `.env`

# ▶️ Installation & Running

## Clone Repository

```bash
git clone https://github.com/dilipgowdaan/vaidya-mithra.git
```

## Navigate to Project

```bash
cd vaidya-mithra
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
